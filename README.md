## 動かし方

`fetch()` でJSONを読み込む構成のため、`index.html` を直接ダブルクリックして
開くとブラウザのセキュリティ制限（CORS）で読み込みに失敗します。
このフォルダ内で簡易サーバーを立てて開いてください。

```bash
cd game
python3 -m http.server 8000
# その後スマホ/PCブラウザで http://localhost:8000 を開く
```

## 既知の簡略化（プロトタイプゆえの割り切り。要相談）

1. **ストーリー再生中のリロード**：現在は「ストーリーパート全体をリロード時に最初から再生し直す」実装です（途中の行までは保存していません）。途中復帰が必要か確認したいです。
2. **メッセージログの永続化**：ログ内容(`messageLog`)はメモリ上のみで、リロードすると消えます。セーブに含めるべきか確認したいです。
3. **SE/BG単独行のテンポ**：ストーリーデータ上、`[SE:...]` や `[BG:...]` のみの行も1タップ必要な1コマとして扱っています。テンポが間延びする場合は、自動で次行へ進める（ノータップ）仕様に変更可能です。
4. **ギミック成功時のメッセージ表示時間**：正解時のメッセージ表示直後にモーダルを閉じるため、一瞬しか見えません。少し間を置く演出に調整可能です。
