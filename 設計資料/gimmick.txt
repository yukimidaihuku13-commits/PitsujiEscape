/* ドアBの電子錠 */
タグ：gimmickLockDoorB
名前：ドアBの電子錠
正解：3952
画像：gimmick_DoorA

【解除方法】
1. 左の上下から、左の枠に入る絵（りんご）を選択する
2. りんご選択時の右の数値の表示から、数値"3952"の位置をタップする
3. OKボタンを押す

【付則情報】
・左の空白は、りんご・ぶどう・バナナ・みかん・桃が入る。
・右の空白には、１～９までの数字が入る
・右の空白に入る数字の並びは、左の空白に入る果物の絵によって、右の数字の並び方が変わる
#以下左の果物と右の数字の配置の対応表
ぶどう：123 456 789
バナナ：357 924 618
りんご：419 237 865
みかん：987 615 324
桃　：691 582 473
・左枠がりんごの時の"3952"位置をタップする
・正解は「左枠がりんごの状態で3952」のみ。他の果物の並びでたまたま3952と押しても不正解
・左枠は▲▼で切り替わる(ぶどう→バナナ→りんご→みかん→桃→ぶどう…のループ。最初はぶどう)。切り替えると入力中の数字は消える
・果物の画像は未用意のため、現在は果物名の文字で表示

【参考情報】
・りんごは、焼かれた食パン（itemToastedBread）に書かれている
・数値は、冷凍後の青い紙（itemFrozenBluePaper）に書かれている


/* 玄関ドアの電子錠 */
タグ：gimmickLockEntrance
名前：玄関ドアの電子錠
正解：ESCAPE
画像：gimmick_DoorEntrance

【解除方法】
1. 1行目 RICE からEの位置を選択する
2. 2行目 PASTA からSの位置を選択する
3. 3行目 CAKE からCの位置を選択する
4. 4行目 TOAST からAの位置を選択する
5. 5行目 PIZZA からPの位置を選択する
6. 6行目 SCONE からEの位置を選択する
 # 1 ~ 6は順不同
7. OKボタンを押す

【付則情報】
・選択した行の右にある枠に、選択した文字が表示される
・選択した文字が上から"ESCAPE"となればOK
・選択した文字部分は色が変わる
・同じ文字を二度選択すると、選択解除となる
・すべての行を選択した後、ＯＫボタンを押す
 （現在の画像には書いていない）

【参考情報】
・"ESCAPE"の文字(暗号文字)は、部屋の電気の色を変えて、絵(itemIllust)を確認すると表示される
・暗号文字の解読として塩"SALT", 電話"PHONE"を使う


/* チャット画面 */
タグ：gimmickPcGame
名前：チャット画面
正解：送り先.ぴかくま　A.サーカステント　B.お寺
画像：pic_tmp_gimmickPcGame

【解除方法】
1. ゲームのフレンドから、ぴぐま(ゲーム内の名前: ぴかくま)を選択する
   選択肢は ぴのくま / ぴりくま / ぴよくま / ぴかくま の4つ。正解は ぴかくま
2. Aの選択肢からサーカステントを選択する
3. Bの選択肢から寺を選択する
4. 証拠写真を添付する
5. 送信ボタンを押す

【付則情報】
・送り先の選択画面の横に、ゲームのランキング(仮)を表示する。後で画像になる予定
  ランキング
  1.ぴかくま
  2.ぷるゃ
  3.黒くま
  4.たぴおか
  #トッププレイヤーという情報が調査ノートに書いてあるため、ランキングに乗っている人物であることが分かる
・ぴかくま以外を選択した場合は先に進まず、"この人じゃないっぴ……"というメッセージを出す(仮の文言)
・画面が縦に長いため、×ボタンに加えて画面下部にも閉じるボタンを置く(送り先の選択画面・チャット画面とも)
・A,Bを入力した時点で間違えていた場合、"これではこの場所が間違えて伝わってるっぴ"というメッセージを出す
・A,Bともに正解の場合、"これで良しっぴ" "あとは写真を添付してぴぐまを呼ぶっぴ"というメッセージを出す
・添付は、添付ボタンをタップすると、カメラでパソコンに転送されたぴつじの写真が添付される(所持品のアイテムは使わない。再度タップで添付を外す)
・送信ボタンは、A,Bともに正解かつ写真を添付している時のみ押せる
・A,Bの穴埋めをタップして選択中にし、候補から文字列を選ぶ(選び直し可)
・画像は地図画像となっていて、家の位置が何か所か書いてある
・チャット欄に表示する文字は穴埋めになっており、選択肢の文字列を選ぶ。
#以下文字
//1行目
ぴつじは預かっている。
//2行目
ここの前の道をまっすぐ歩くと[ A ]があって
//3行目
ここからは高層ビルが邪魔で[ B ]は見えない。
//4行目
速くここまで助けに来い。

A, Bとも選択肢は
・お寺
・サーカステント
・学校
・高層ビル
の4択

【参考情報】
・段ボールの宛先の隣にメモが貼ってあり、メモには"お隣の工場のものです。誤配されていたので置いておきます"と書かれている
・証拠写真は、ぴつじの部屋の小窓にカメラを使うと、PCに転送される仕組み。カメラ使用前にはギミックが起動できない

/* 電話ギミック */
タグ：gimmickPhone
名前：電話ギミック
正解：#7*27
画像：pic_tmp_gimmickPhone

【解除方法】
1. 電話画面で#7*27とタップする
2. 電話マークをタップする

【付則情報】
・7*27で電話マークをタップした場合、"ぴさぎは不在みたいだッピ"というメッセージを出し失敗
　SE:"電話に出ない音"も併せて流す
・それ以外で電話マークをタップした場合、"「この番号は存在しない」ってメッセージが流れてるッピ"というメッセージを出し失敗
　SE:"電話がつながらない音"も併せて流す
・成功した場合"ぴつじは預かってるっぴ" "速く助けにくるっぴ"　"困ってるっぴ！"とメッセージをメッセージを出し成功
　SE:"留守番電話を残すピーという電子音"も併せて流す
・電話マークをタップすると(成功・失敗とも)入力した番号は消える。入力のやり直し用にクリアボタンを置く

【参考情報】
・ぴさぎの名刺の表側に電話番号 7*27　と書いてある
・ぴさぎの名刺の裏側に、不在時は留守番電話にメッセージを残してください　と書いてある
・棚に電話の説明書があり、その画像を確認すると、電話番号の先頭に#をつけると留守番電話にメッセージが残せることがわかる

/* 写真ギミック */
タグ：gimmickPhoto
名前：写真ギミック
正解：NA
画像：pic_tmp_gimmicPhoto

【解除方法】
1. 写真の中のマラカス部分を選択する
2. 写真の中のタンバリン部分を選択する
 # 1, 2は順不同
3. OKボタンを押す

【付則情報】
・選択位置以外をタップした場合は、"ここじゃないっぴねえ"というメッセージを表示する
・選択位置を選択した場合、該当位置を〇で囲む
 (TBD. 画像が用意される可能性あり。現在は赤い〇で表示)
・選択位置: マラカス = 写真の左下(ぴぐまが持っているマラカス) / タンバリン = 写真の右上(ぴさぎが持っているタンバリン)
・選択位置は、見つけるまでは見えない(デバッグ表示中は枠を表示)
・正解位置を選択した場合、再度タップしても選択解除はされない
・解除すると、そのままぴさぎ(spotPisagi)の"gimmickPhotoクリア時"の処理(買い出し → マラカス・タンバリン入手)を行う

【参考情報】
・マラカス・タンバリンの情報は、調査ノートに書いてある
