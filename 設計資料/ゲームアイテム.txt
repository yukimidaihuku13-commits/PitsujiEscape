アイテム一覧
#使用後の状態について
消失：使用後にアイテム一覧から消す。
残存：使用後アイテム一覧に残る(同一操作パートのみ)。操作パート切り替わり時に、残存アイテムはアイテム一覧から全て消す。

/* チョコレート */
タグ：itemChocolate
入手場所：spotFridgeCompartment // 冷蔵庫の冷蔵部分
入手可能パート：PlayPart == 2
使用対象：spotPitsujiDoorGap // ぴつじ部屋のドア下隙間 (ぴつじに渡す)
使用後：消失

/* 青い紙 */
タグ：itemBluePaper
入手場所：spotDrawer　// 棚の引き出し
入手可能パート：PlayPart == 3
使用対象：spotFreezerCompartment //冷蔵庫の冷凍部分
使用後：消失　→　itemFrozenBluePaper // 冷凍後の青い紙に変化

/* 冷凍後の青い紙 */
タグ：itemFrozenBluePaper
入手場所：青い紙の変化
入手可能パート：PlayPart == 3
使用対象：NA　//特定の使用対象なし。アイテム自体を確認すると、紙には4桁の数字がかかれている
使用後：NA
