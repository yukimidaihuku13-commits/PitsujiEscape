クリックポイント一覧
<アクション>タップした時にどのような処理が行われるか。
・メッセージ: メッセージを表示する
・取得: アイテムを取得する。
・使用: アイテムを使用する。　#アイテムを使う時は、所持品の該当アイテムを選択してクリックポイントをタップする
・移動: 視点移動。(部屋の移動含む)
・ギミック: ギミックが起動する。(ギミック視点に移動する)
・処理: 次のステップに進む。(内部でフラグが立つだけ)
・表示: アイテム画像を表示する。基本は再クリックで画像を消す
・差分: 背景差分の画像を表示する。
・SE: 効果音を鳴らす。（音のイメージ。SE自体はあとで探す）

/* 本棚 */
タグ: spotBookshelf
<アクション>
If.ぴさぎの名刺(itemPisagiCard)取得後
	#ランダムでいずれかのメッセージを表示
	メッセージ: "クローズド・サークルといえばアガサクリスティっぴ"
	メッセージ: "シャーロック・ホームズは名作だっぴねぇ"
ElseIf.PlayPart == 6
	メッセージ: "そういえば名刺をしおり代わりにしてたっぴ"
	SE: 本を開くぱらっという音
	表示: 本の画像(しおりが挟まっている)
	取得: itemPisagiCard // ぴさぎの名刺
ElseIf.PlayPart == 5
  #クリック回数は総計. タップ毎に1行ずつ表示され、3行目の後は1行目に戻ってループする。
  If.クリック回数 >= 3
    メッセージ:”別の記号に置き換えられた絵文字を解読するホームズは凄いっぴ”
  ElseIf.クリック回数 == 2
    メッセージ:”換字式暗号の中で一番好きだっぴ！”
  Else.// 1回目
    メッセージ: "ホームズの踊る人形だっぴ！”
ElseIf.PlayPart == 3
	#クリック回数は総計. タップ毎に1行ずつ表示され、4行目の後は1行目に戻ってループする。
	If.クリック回数 >= 4
		処理: クリック回数リセット
		メッセージ: "と書いてある。謎を作る時に参考にした本。"
	ElseIf.クリック回数 == 3
		メッセージ: "冷やすと文字が消える。"
	ElseIf.クリック回数 == 2
		メッセージ: "温めると文字が消える。"
	Else. // 1回目
		メッセージ: "インクについて、という本だ。"
Else.
	メッセージ: "最近のお気に入りはホームズの踊る人形だ"

/* 電話 */
タグ: spotPhone
視点: viewPhoneStand
<アクション>
If.PlayPart > 6
	メッセージ: "懐かしの黒電話。触り心地がいい"
ElseIf.PlayPart == 6
	If.ぴさぎの名刺選択中
		使用: itemPisagiCard　// ぴさぎの名刺
		メッセージ: "留守番電話だ。すぐ来てほしいとメッセージを残しておこう"
	Else.
		メッセージ: "どうにかぴつじを脱出させたい！"
ElseIf.PlayPart == 4
	If.ブラックライト選択中
		使用: itemBlackLight　// ブラックライトを使う
		メッセージ: "電話になにかが浮かび上がってきた"
		表示:PHONEを踊る人形文字にした画像
	Else.
		メッセージ: "どうにかぴつじを脱出させたい！"
Else.
	メッセージ: "いいよな黒電話"
