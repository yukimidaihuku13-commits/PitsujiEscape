クリックポイント一覧
<アクション>タップした時にどのような処理が行われるか。
・メッセージ: メッセージを表示する
・取得: アイテムを取得する。
・使用: アイテムを使用する。　#アイテムを使う時は、所持品の該当アイテムを選択してクリックポイントをタップする
・移動: 視点移動。(部屋の移動含む)
・ギミック: ギミックが起動する。(ギミック視点に移動する)
・処理: 次のステップに進む。(内部でフラグが立つだけ)
・表示: アイテム画像を表示する。基本は再クリックで画像を消す
・差分: 背景差分の画像を表示する。
・SE: 効果音を鳴らす。（音のイメージ。SE自体はあとで探す）

/* 配信用カメラ */
タグ: spotPcStream
視点: viewDesk
<アクション>
If.PlayPart == 1 　// 操作パート1の時
	SE: カチッという音
	処理: 操作パート1クリア //配信が始まる
ElseIf.PlayPart == 2　// 操作パート2の時
	If.チョコレート使用済
		SE: カチッという音
		処理: 操作パート2クリア
	Else.
		メッセージ: "ぴつじは何をしたらテンション上がるかな"
ElseIf.PlayPart == 3　// 操作パート3の時
	If.ドアBを開けるギミック(gimmickLockDoorB)を解除済み
		SE: カチッという音
		処理: 操作パート3クリア //配信が始まる
	Else.
		メッセージ: "ちょっと解いてくるか。何がそんなに嫌なんだ？"
ElseIf.PlayPart == 4　// 操作パート4の時
	If.玄関ドアのギミック(gimmickLockEntrance)解除済み
		SE: カチッという音
		処理: 操作パート4クリア //配信が始まる
	Else.
		メッセージ: "これはぴつじとの勝負！"
		メッセージ: "ぴつじを部屋から脱出させてみせる！"
ElseIf.PlayPart == 5 // 操作パート5の時
	If.タオルケットとクッションを使用済み
		SE: カチッという音
		処理: 操作パート5クリア // 配信が始まる
	Else.
		メッセージ: "これはぴつじとの勝負だ！"
		メッセージ: "何をしたら部屋から出てくるんだ？！"
ElseIf.PlayPart == 7　// 操作パート7の時
	If.音楽をHAPPYに変更済み
		SE: カチッという音
		処理: 操作パート7クリア //配信が始まる
	Else.
		メッセージ: "これで決める！"　　
Else.
	// 実質操作パート6のみ
	メッセージ: "今はその時じゃない...か......"
