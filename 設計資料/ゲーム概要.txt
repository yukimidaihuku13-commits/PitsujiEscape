【ゲームの全体プロット･目的】
黒ぴぐまが脱出要素をすべて解除し、ぴつじのやる気を出して、ぴつじを部屋から外に出す。

【ゲームタイトル】
ぴつじ脱出ゲーム　//　プロローグ終了まで
↓
ぴつじを部屋から脱出させるゲーム　//　プロローグ終了後、タイトルを変更する
// タイトルは画面上部のヘッダーに表示する。プロローグ(ストーリーパート1)終了後＝操作パート2以降で切り替える。
// 切り替え時の演出は未定(現状は切り替わるだけ)

【操作アイコン】
ログ：表示したメッセージのログが表示できる
ヒント：ヒント機能。次にやることがわかる。
早送り：メッセージ・ストーリーの早送り。メッセージウィンドウの付近にある
　　　　タップすると1行ずつ高速で自動送りする(もう一度タップで停止)。ストーリーパートの最後まで進むと自動で解除
キャラ顔画像：タップすると次やる事のメッセージ(台詞)が表示される。操作パート1〜7は黒ぴぐま、操作パート8はぴつじ
設定：設定が変えられる。音量操作。著作権表示。いつでも押せる(操作パート開始時メッセージの表示中・ストーリー中も含む)

【所持品アイコン】
所持した順番に並ぶ。一度に選択出来るのは一つだけ。
・タップするとそのアイテムを選択。
・選択中に同一アイテムをタップすると、アイテムの拡大画像を表示。(選択は解除されない)
・さらに同一アイテムをタップすると、選択解除。
・選択中に別のアイテムアイコンをタップすると、選択されるアイテムが移動する。(移動先のアイテムは「選択」から始まる)
(アイテム拡大画像が未用意の間は、アイテム名を表示した仮枠で代用する)
・アイテム選択時に、効果音Se_ItemIconを流してください。

【アイテム拡大画像表示時】
・拡大画像の下に、アイテムについての説明文(メッセージ)を表示する。(説明文は items.json の description)
・画面上のいずれかをタップすると、メッセージが消えて閉じるボタンを表示する。(説明文が複数行ある場合は、タップ毎に次の行を表示し、最後の行の次で閉じるボタン)
・閉じるボタンが押されると、拡大画像が閉じる。
・ぴさぎの名刺のように表/裏がある物は、タップする度に表→裏→表…と切り替わる(閉じるボタンは常に表示)。

【所持品の使い方】
所持品アイコンを選択した状態で、クリックポイントをタップする。

【設定・ヒント・ログボタン】
アイコンを押す際、Se_SelectIconのSEを流してください。

【ヒントについて】
ヒントページに移行する。
各操作パートごとにやることが提示される。
各操作パート3～5のヒント項目があり、タップ毎に捲れていく。

【セーブ/リロード】
必要。オートセーブ/オートリロード想定。
・ストーリーパートの途中でリロードした場合は、そのストーリーパートを最初から再生する。
・同じゲームを複数のタブ/ウィンドウで開いた場合、別のタブでゲームが進むと、古いタブは操作・保存・BGMを止めて
  「再読み込み」を促す(古い状態でセーブを上書きしないため)。
・セーブデータが壊れている/改ざんされている場合は、読める項目は補正して再開し、進行位置が不正な場合は破棄して最初から。
・メッセージログはセーブしない(操作パート開始時にリセット)。1パート内でも最新200件まで保持し、古いものから消す。

【設定画面について】
・音量操作を行う(SE/BGMそれぞれ 大・中・小・消 の4段階。初期値は中。設定はセーブデータとは別に保存し、セーブ削除でも残る)
  ※音声ごとに元の音の大きさが違うため、「中」の時の音量を data/audio.json の volume で音声ごとに設定できる(省略時0.6)。
    大は中の1.5倍(最大1)、小は中の0.5倍、消は無音。
・著作権表記(data/credits.json)を表示する
・連絡先等の表示
・特に音源においてフリー素材を使用予定なので、その際の著作表示などを行う
・その他必要な設定があれば随時追加

【SE・BGM】
・音声ファイルの割り当ては data/audio.json に集約する(キー名→ファイル)。未設定(file:null)の音は鳴らさない。
・BGMは常に1曲だけ流れる。優先順: 画像表示中だけ流すBGM(パーティー画像) ＞ オーディオで選んだ曲(「通常」以外) ＞ 操作パート/ストーリーのBGM。
  ただしストーリー中は、BGMの指定がある行以降はオーディオで選んだ曲よりストーリーのBGMを優先する(ストーリーの演出どおりに切り替わる・止まる)。
・操作パートのBGMは playParts.json の bgm。指定の無いパートは直前のパートの曲を引き継ぐ。ストーリーは行ごとの bgm で切り替わる(指定行まで前の曲が続く)。
  [BGM:止める] の行でBGMを止める(storyParts.json の stopBgm)。
・ストーリーで流れたBGMはオーディオで選べる曲に追加され、次の操作パートの開始時メッセージの後に"BGM 〇〇 がオーディオに追加された"と表示する。
  BGM名は data/audio.json の bgm の name。未設定(null)の間はファイル名から BGM_ を除いた先頭6文字を暫定表示する(例: The Da)。
・視点移動・ノート・モーダル・リロードでは曲を最初から流し直さない。スタート画面・タイトルへ戻った時は止める。エンディング画面ではストーリー8の曲が続く。
・タブが裏に回った間はBGMを止め、戻ると続きから再開する。
・メッセージの後に書かれたSEは、そのメッセージを送った時に鳴る(資料の記載順どおり)。同じSEの80ms以内の連続は1回にまとめる。
・ブラウザの自動再生制限でBGMが流れなかった場合は、次に画面をタップした時に流れ始める。
