/* 調査ノート */
// 旧 調査ノート1(viewNote1)・調査ノート2(viewNote2) を1つの視点にまとめた。
タグ：viewNote
矢印移動：NA // 矢印は無し。画像の下の「閉じる」ボタンで viewDesk に戻る
// 画面構成
・ページ画像 // タップで次のページへ移動する
・閉じるボタン // 画像の下に常に表示。いずれのページでも、押すとノートを閉じて viewDesk に戻る
// ページ一覧（全5種類。ノートを開くと毎回 ページ1左 から表示する）
1.ページ1左[note1left]
2.ページ1右[note1right]
3.ページ2左[note2left]
4.ページ2右[note2right]
5.ページ3左[note3left] // 操作パート7のみ表示可能。写真(itemPhoto)入手ページ
// ページ移動のルール
・ページを表示した時に、そのページのメッセージを表示する
・操作パート6まではページ2右が最後のページ（それ以上は進まない）
・操作パート7では、ページ2右を表示した状態で3回タップするとページ3左が表示される
  (写真入手後に開き直した場合は、ほかのページと同じく1回のタップでページ3左へ進む)
・最後のページまで移動したら、それ以降はページを移動させない
// 各ページのメッセージ・処理はゲームクリックポイント.txt「調査ノート viewNote」参照
